# Field audit backports — APWHM Unit 3 (2026-08-24)

First run of the comparison protocol (`docs/spiral-studio-handoff.md`, Part 3) against real materials: APWHM Unit 3 (Land-Based Empires) — 4 lesson briefs + PPT scripts, the unit test, the companion packet, pacing guide, day-by-day schedule, the warm-up bank, and the cumulative-review decks. These are the findings that flow back into the playbook.

## Backports — where the field materials beat the design

1. **The recall-check anchor (AI-vs-No-AI DBQ sequence).** Schedule Days 18–20 run: a DBQ skills primer with a collected "Prediction" writing task → a working session on a 7-document set spanning Units 1–3, half the room with closed laptops, half directing an AI → a surprise, silent, handwritten recall check the next class ("Without looking at your notes or the documents, write everything you remember"). A designed retention experiment and an integrity architecture in one; the playbook has nothing like it. Proposed: add as a named B-day variant.

2. **Running Theme Tracker.** One page per CED theme; each page a 9-row table (one row per unit, CONTINUED vs CHANGED), filled at every unit close in ~15 minutes, so by April each page shows one theme moving across the whole course. Stronger than the playbook's ID-card "so what" fields for theme continuity. Proposed: adopt as a standard course artifact.

3. **Cumulative unit-test items are already field practice.** The Unit 3 test embeds 5 of 25 MCQs from Units 1–2 "per pacing-guide design." The playbook's 30% lagged target should cite this 20% live practice as the working precedent rather than presenting lagged items as a new ask.

4. **2027-format execution exists in the field.** The unit test is built as "May 2027 Exam Format" with non-text stimuli throughout (Mughal miniature, territorial-extent data table, woodcut, Qing expansion map) and a parked non-text SAQ3 (Bichitr, "Jahangir Preferring a Sufi Shaikh to Kings"). The playbook's framing that current prep materials all model the old format understates how far these assessments are already converted.

## Amendments — where the design got this context wrong

1. **Review season is 6 days here, not 12.** The calendar has 71 section meetings, content through Day 65, review Days 66–71, all pre-exam. The playbook's 12-block review season does not fit without cutting content days it elsewhere protects. Amendment: carry a compressed-review variant in which the daily lagged opener does most of the spiral work and review season is 6 blocks of mixed retrieval + repair.

2. **Sourcing acronym resolved by David, 2026-08-24: HIPP for both courses, reversing the handoff's locked HAPP decision.** APUSH already uses HIPP uniformly (~119 uses; zero migration needed). APWHM is now the migration target: its packets and Skills Handbook use HAPP (~52 uses) while its Writing Toolkit already uses HIPP, so the sweep resolves that pre-existing split toward HIPP. The pending-fix list inverts accordingly: the assessment-builder and lesson-planner skill tables should document HIPP (Historical situation, Intended audience, Point of view, Purpose), and this repo's playbook, pacing doc, and day-skeletons reference have been migrated in this commit series.

3. **The retrieval-opener build is a wiring job, not an authoring job, for this course.** A 180-item recall bank with a full answer key (the 5 Steps to a 5 bell-ringer set) already sits in `Warm-Ups/` with no mapping to course days, and the schedule's own warm-up spec says "hook question," not retrieval. The playbook's build list should distinguish wire-the-existing-bank from write-new-items.
