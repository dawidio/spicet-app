# The 70-Block Calendar — AP World History: Modern

Companion to `ap-history-70-day-playbook.md`. Block = one 75-minute A/B meeting. Day types (defined in Playbook 5.1): **A** Studio · **B** Document Day · **C** Writing Workshop · **D** Summit/Defense · **E** Spiral Day.

Allocation logic: blocks proportional to exam weight (U1–2: 16–20% → 9 blocks · U3–6: 48–60% → 32 blocks · U7–9: 24–30% → 15 blocks · review: 12 blocks), content done by early April, review timed to the Cepeda ridgeline (final relearning passes 2–4 weeks out). Every block still opens with the cumulative retrieval opener and closes with exit + prequestions — the calendar only names the main event.

**The standing homework rhythm (never listed per-block below):** before every content block — Heimler/WHP topic + entry check; twice weekly — 15-min scheduled relearning session; weekly — one component write or 90-second recorded defense.

## If you lose days (and you will)

Cut in this order, never touching the openers or the writing reps:

1. Block 57's second capstone block (U9 compresses to 2).
2. One Spiral Day (the openers carry the spiral).
3. Block 45 (fold interwar into 44/46 flips).
4. Mock #2 becomes take-home FRQs, peer-scored.
5. Never cut: launch experiment, DBQ workshops, Summit/exhibit defenses, mock #1 + autopsy, blocks 59–63.

## APUSH conversion notes

Same architecture, same day-type rotation, same review season. Reallocate: Periods 3–8 are APUSH's heavy band (~74% combined); Periods 1–2 get ~5 blocks, 9 folds into review as a thematic capstone. The DBQ range (1754–1980) means document days concentrate mid-course. Your assessment-builder's APUSH period list slots straight into the Phase tables.
