# Day skeletons — the five block types (75-minute A/B)

Every block, regardless of type, opens with cumulative retrieval and closes
with exit + prequestions. Only the middle changes.

## Type A — Studio Day (~50% of days)

| Min | Segment | Notes |
|---|---|---|
| 0–12 | Cumulative retrieval opener | Lagged quiz or brain dump → immediate whole-class feedback → students mark each item knew / lucky / wrong in their tracker |
| 12–17 | Sentence sprint | because/but/so expansion or rubric-frame drill on current content |
| 17–30 | Targeted clarification | NOT first exposure — address what the entry checks showed was misunderstood. Mayer-clean slides: no decoration, no reading aloud |
| 30–60 | Studio block | Rotate: theme-chart work in the app, 2-document HAPPY drill, peer-instruction stimulus MCQs (individual commit → pair argument → revote), or anchor-project work |
| 60–72 | Component writing rep | SAQ (ACE) / thesis rep / paragraph — scoring mode from the rotation below |
| 72–75 | Exit + preview | One retrieval item + one calibration judgment; prequestions for tonight's video; deck-due reminder |

## Type B — Document Day (~1 per week)

Opener (12) → document lesson around ONE central historical question, sources
pre-excerpted (25–40; brief `ap-world-discussion-questions` for the tiered
question set) → whole-class argument over the central question (15) → written
synthesis: one ACE paragraph answering it (10).

## Type C — Writing Workshop (~3 per unit once essay instruction starts)

Opener (10) → worked example: class scores a real College Board sample against
the rubric before writing (15) → timed component or full write (25–40) →
score-and-argue: self-score, swap for peer score, argue discrepancies to the
rubric text (15). Teacher collects all, spot-scores a third, whole-class
feedback next block.

## Type D — Summit / Defense Day (6–8 per year)

Conference-style: 3 stations, each panel = David + 2 trained peer panelists,
8-minute slots. Non-presenting students hold a structured evaluator role —
score ONE rubric row + write one question they'd ask. Twenty students clear in
two blocks. Defense rubric scores reasoning (SASPD Argumentation/Claims bands),
never fluency; questions previewed.

## Type E — Spiral Day (1 per ~2 weeks; default sub-day plan)

Full-period mixed retrieval and repair: interleaved MCQ set from the AP
Classroom Question Bank → error autopsy in pairs → relearning session on each
student's knew/lucky/wrong backlog (app Review mode) → one mixed-period SAQ.
Self-contained; brief `ap-world-sub-plans` with "Spiral Day packet" when a sub
runs it.

## Scoring-mode rotation (the student-side scoring layer)

Sequencing law: **norm first** (see `norming-protocol.md`). A skill enters
peer scoring only after the class has scored anchor papers on it.

| Rep | Mode | Mechanics |
|---|---|---|
| First rep of any new skill | **Whole-class norming** | Score CB anchor set together (a high / mid / low paper); argue to rubric text |
| Weekly component reps | **Peer, rubric-row-limited** | "Today we only score evidence." Scorer signs the score |
| Every 2–3 weeks | **Self, sample-matching** | Rank three anonymized responses, place your own, justify in rubric language |
| Full timed writes | **Self → teacher spot-score** | Student self-scores same day; David spot-scores a rotating third; whole-class feedback slide next block |
| Gradebook-bound work | **Teacher only** | `grading-stress-test` → `ap-world-student-feedback`; SASPD conversion → Schoology |
| Monthly | **Calibration audit** | David re-scores 3–4 peer-scored papers blind; discrepancies > 1 point trigger a re-norming session |
